Fix Tool for Roblox CDN (tr.rbxcdn.com)

📦 Fix Tool — это простая утилита на Python с графическим интерфейсом (GUI), которая автоматически добавляет необходимый IP-адрес для хоста tr.rbxcdn.com в системный файл hosts на Windows. Это помогает решить проблемы с загрузкой ресурсов или подключением к серверам Roblox, если они заблокированы или некорректно маршрутизируются вашим провайдером.

✨ Особенности

• 🖥️ Интуитивный GUI: Минималистичный и чистый интерфейс, созданный на базе tkinter.
• 🛡️ Автоматический запрос UAC: Программа сама определяет наличие прав администратора и запрашивает их для редактирования системных файлов Windows.
• 🔍 Проверка дубликатов: Скрипт проверяет файл hosts перед записью. Если строка уже добавлена, утилита просто сообщит об этом и не будет дублировать код.
• 🔏 Безопасность: Никаких сторонних библиотек, используется только стандартная библиотека Python.

🚀 Как запустить


Из исходного кода (для разработчиков)

1. Убедитесь, что у вас установлен Python 3.x.
2. Склонируйте репозиторий или скачайте файл main.py.
3. Запустите скрипт через терминал или двойным кликом:bash
python main.py


Сборка в .exe (для пользователей)

Если вы хотите скомпилировать этот скрипт в один исполняемый файл для удобства пользователей, используйте pyinstaller:

1. Установите PyInstaller:bash
pip install pyinstaller


2. Соберите проект (флаг --noconsole скроет черное окно консоли, а --onefile соберет всё в один файл):bash
pyinstaller --onefile --noconsole main.py

3. Заберите готовый .exe файл из папки dist/.

🛠️ Что именно делает программа?

При нажатии на кнопку ФИКС утилита добавляет следующую строчку в файл C:\Windows\System32\drivers\etc\hosts:
text
18.65.39.105 tr.rbxcdn.com
